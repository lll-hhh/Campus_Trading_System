# 凤凰汽配管理系统 - 测试计划与用例文档

## 1. 测试策略
本项目的测试工作遵循“尽早介入、全面覆盖”的原则，分为四个阶段：
1. **单元测试 (Unit Testing)**：针对后端 API 逻辑和前端组件进行独立测试。
2. **集成测试 (Integration Testing)**：测试各模块间的接口调用及数据流转。
3. **系统测试 (System Testing)**：模拟真实业务场景，进行全流程功能验证。
4. **性能测试 (Performance Testing)**：验证系统在高并发下的稳定性。

## 2. 测试环境
- **操作系统**：Ubuntu 22.04 LTS
- **数据库**：MySQL 8.0.30
- **测试工具**：Pytest (后端), Vitest (前端), JMeter (性能), Playwright (UI 自动化)

import pytest
from httpx import AsyncClient

@pytest.mark.asyncio
async def test_login_success(client: AsyncClient):
    response = await client.post("/api/v1/auth/login", json={
        "username": "admin",
        "password": "password123"
    })
    assert response.status_code == 200
    assert "access_token" in response.json()

@pytest.mark.asyncio
async def test_create_part_permission_denied(client: AsyncClient):
    # 使用普通用户 Token
    headers = {"Authorization": "Bearer user_token"}
    response = await client.post("/api/v1/parts", headers=headers, json={
        "name": "非法零件",
        "oem_code": "BAD-001"
    })
    assert response.status_code == 403
