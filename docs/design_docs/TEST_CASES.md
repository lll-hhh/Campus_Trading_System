# 凤凰汽配管理系统 - 详细测试用例

## 1. 身份验证与权限模块 (Auth & RBAC)

### TC-AUTH-01: 管理员登录验证
- **描述**: 验证管理员账号是否能成功进入后台管理系统。
- **步骤**:
    1. 访问 `/login` 页面。
    2. 输入管理员账号 `admin` 和密码。
    3. 点击登录。
- **预期结果**: 成功跳转至 `/admin/dashboard`，侧边栏显示所有管理功能。

### TC-AUTH-02: 越权访问拦截
- **描述**: 验证普通用户无法访问管理员页面。
- **步骤**:
    1. 以普通用户身份登录。
    2. 手动在浏览器地址栏输入 `/admin/performance`。
- **预期结果**: 系统显示 403 Forbidden 页面或自动重定向至首页。

---

## 2. 零件管理模块 (Inventory Management)

### TC-INV-01: 零件发布流程
- **描述**: 验证用户发布零件的功能。
- **步骤**:
    1. 进入“发布零件”页面。
    2. 填写标题、价格、分类（如：发动机系统）。
    3. 上传零件照片。
    4. 提交。
- **预期结果**: 提示“发布成功，等待审核”，数据库 `items` 表新增记录，状态为 `pending`。

### TC-INV-02: 零件审核操作
- **描述**: 验证管理员审核功能。
- **步骤**:
    1. 管理员进入“系统运维” -> “零件审核”。
    2. 找到 TC-INV-01 发布的零件。
    3. 点击“通过”。
- **预期结果**: 零件状态变为 `available`，在市场搜索中可被查找到。

---

## 3. 交易与采购模块 (Trade & Procurement)

### TC-TRADE-01: 采购流程闭环
- **描述**: 验证从下单到成交的完整逻辑。
- **步骤**:
    1. 用户 A 将零件加入“采购车”。
    2. 点击结算并确认订单。
    3. 用户 B（卖家）确认发货。
    4. 用户 A 确认收货。
- **预期结果**: 零件状态变为 `sold`，`transactions` 表生成成交记录，管理员仪表盘成交数增加。

---

## 4. 系统监控与 AI 模块 (Monitoring & AI)

### TC-MON-01: 性能指标实时性
- **描述**: 验证监控中心数据是否实时更新。
- **步骤**:
    1. 打开“性能监控”页面。
    2. 在另一个窗口频繁刷新零件列表产生查询压力。
- **预期结果**: 监控页面的 QPS 指标和平均查询耗时发生动态变化。

### TC-AI-01: AI 异常诊断
- **描述**: 验证 AI 助手对系统状态的分析能力。
- **步骤**:
    1. 进入 AI 助手页面。
    2. 输入“分析当前数据库健康状况”。
- **预期结果**: AI 返回包含连接数、延迟、资源占用等指标的结构化报告，并给出优化建议。

---

## 5. 数据库管理模块 (Database Operations)

### TC-DB-01: SQL 沙箱执行
- **描述**: 验证管理员执行 SQL 语句的功能。
- **步骤**:
    1. 进入“系统运维” -> “SQL 执行器”。
    2. 输入 `SELECT COUNT(*) FROM items;`。
    3. 点击执行。
- **预期结果**: 下方表格正确显示零件总数。
