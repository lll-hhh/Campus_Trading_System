# 凤凰汽配管理系统 - UI 原型与功能说明

本章节详细描述系统各核心页面的 UI 布局、交互逻辑及功能点。页面截图请参考对应的占位符进行替换。

---

## 1. 登录页面 (Login Page)

### 1.1 页面布局
- **中心区域**：登录卡片，包含系统 Logo、系统名称（凤凰汽配管理系统）。
- **输入项**：用户名输入框（带图标）、密码输入框（支持显示/隐藏切换）。
- **操作项**：登录按钮（蓝色高亮）、"记住我"勾选框、找回密码链接。

### 1.2 核心功能
- **身份验证**：对接后端 `/api/auth/login` 接口，验证成功后存储 JWT Token。
- **权限路由**：根据用户角色自动跳转至对应的初始页面（如管理员跳转至仪表盘，销售员跳转至订单页）。

## 2. 系统仪表盘 (Dashboard)

### 2.1 页面布局
- **顶部统计卡片**：展示今日销售额、新增订单数、库存预警数、活跃客户数。
- **中部图表区**：
    - 左侧：近七日销售趋势折线图（ECharts 渲染）。
    - 右侧：配件分类占比饼图。
- **底部列表区**：展示最新的 10 条出入库动态。

### 2.2 核心功能
- **实时监控**：自动刷新关键业务指标。
- **快捷入口**：点击统计卡片可直接跳转至对应的管理模块。

## 3. 配件管理页面 (Part Management)

### 3.1 页面布局
- **顶部搜索栏**：支持按配件名称、编码、品牌、分类进行多条件组合查询。
- **操作按钮组**：新增配件、批量导入、导出 Excel。
- **数据表格**：展示配件图片、编码、名称、品牌、适用车型、基准价格、操作列（编辑/删除/查看详情）。

### 3.2 核心功能
- **配件维护**：支持配件信息的增删改查，支持上传配件实物照片。
- **分类联动**：选择大类后自动加载对应的小类。

## 4. 库存管理与预警 (Inventory & Alert)

### 4.1 页面布局
- **库存列表**：展示配件名称、当前库存量、预警下限、库位信息。
- **状态标识**：库存低于下限时，数量显示为红色并带有闪烁预警图标。
- **入库/出库弹窗**：点击操作列弹出表单，输入数量、经办人、备注。

### 4.2 核心功能
- **库存调整**：支持手动盘点调整。
- **预警推送**：系统自动检测低库存配件并汇总至仪表盘。

## 5. 销售订单处理 (Sales Order)

### 5.1 页面布局
- **订单创建页**：
    - 左侧：配件选择区（支持扫码或搜索）。
    - 右侧：待下单列表（采购车），自动计算总价。
- **订单列表页**：展示订单号、客户名、总金额、支付状态、创建时间。

### 5.2 核心功能
- **快速下单**：支持选择客户等级自动应用折扣。
- **支付确认**：支持标记为已支付并自动触发库存扣减。

## 6. 权限与角色配置 (RBAC Settings)

### 6.1 页面布局
- **角色列表**：左侧显示角色树（管理员、仓库主管、销售员等）。
- **权限矩阵**：右侧显示功能菜单树，通过勾选框分配查看、编辑、删除权限。

### 6.2 核心功能
- **动态菜单**：用户登录后，侧边栏仅显示其拥有权限的模块。
- **按钮级控制**：根据权限隐藏或禁用页面上的特定按钮。
