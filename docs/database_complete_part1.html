🗺️ 实体关系图 (Entity-Relationship Diagram)

📐 ER图说明

  • 实体 (Entity): 矩形框表示数据库表
  • 关系 (Relationship): 菱形表示表之间的关联关系
  • 属性 (Attribute): 表内关键字段（详细字段见下方表定义）
  • 基数 (Cardinality): 1:1（一对一）、1:N（一对多）、N:M（多对多）
  • 外键约束: 实线连接表示 FOREIGN KEY 约束
🔍 缩放: 100%

🔍 完整ER图核心关系说明

  • users (核心枢纽): 连接35+张表，包括角色权限、商品交易、消息评论、审计日志、扩展功能等
  • items (商品中心): 被 transactions、favorites、comments、item_images、item_price_history、item_view_history、cart_items 等多表引用
  • transactions (交易核心): 关联 buyer、seller、item 三方，还关联 transaction_review_images
  • RBAC权限体系: users ↔ roles ↔ permissions 通过 user_roles 和 role_permissions 中间表实现多对多关系
  • 消息系统: messages 表关联 sender、receiver、item，并通过 message_attachments 支持附件
  • 评论系统: comments.parent_id 实现评论嵌套回复，comment_likes 实现点赞功能
  • 审计追踪: audit_logs 记录所有表的 INSERT/UPDATE/DELETE 操作
  • 四库同步: conflict_records、sync_logs、sync_tasks、sync_configs 支持 MySQL/MariaDB/PostgreSQL/SQLite 同步
  • 监控系统: performance_metrics、database_health 实时监控数据库性能和健康状态
  • 系统管理: reports 举报系统、notifications 通知、daily_stats 统计、system_configs/settings 配置
  • 扩展功能: user_follows 关注、user_addresses 地址、search_history 搜索历史、credit_score_history 信用分变更、cart_items 购物车、conversations 会话等

⚙️ 数据库编程组件

触发器 (Triggers)

🔧 7个核心触发器

  • trg_after_user_insert: 用户注册后自动记录审计日志
  • trg_before_item_view_update: 商品浏览时更新updated_at
  • trg_after_transaction_complete: 交易完成时更新用户统计和商品状态
  • trg_after_comment_insert: 评论时增加商品咨询量
  • trg_after_favorite_insert: 收藏时增加商品收藏量
  • trg_after_favorite_delete: 取消收藏时减少收藏量
  • trg_after_transaction_rating: 评分时重新计算用户平均评分

存储过程 (Stored Procedures)

📦 3个核心存储过程

  • sp_create_transaction(item_id, buyer_id, buyer_contact)
    → 创建交易，带锁检查商品状态，防止重复下单
  • sp_get_user_stats(user_id)
    → 获取用户完整统计(评分、交易量、在售商品数、收藏数)
  • sp_search_items(keyword, category_id, min_price, max_price, condition_type, offset, limit)
    → 商品全文搜索，支持多条件过滤和分页

视图 (Views)

👁️ 3个核心视图

  • v_item_details: 商品详情视图 - 关联卖家信息、分类信息
  • v_transaction_stats: 交易统计视图 - 按日期汇总交易数据
  • v_user_activity: 用户活跃度视图 - 汇总用户行为数据
